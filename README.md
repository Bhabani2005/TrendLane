# 👗 Trandlane

**Trandlane** is a modern mobile e-commerce app for fashion lovers! 🛍️ Built using **React Native**, it delivers a smooth and stylish shopping experience right on your phone. Users can browse products, add to cart, and explore the latest trends in fashion — all in one elegant app.

## ✨ Features

* 🛒 **Product Listing** – Browse fashion products by category
* 💖 **Wishlist** – Save your favorite items for later
* 🧺 **Shopping Cart** – Add, remove, and edit cart items
* 🔐 **User Authentication** – Sign up / Login securely
* 🎨 **Responsive UI** – Sleek and modern design with responsive components

## 🛠️ Tech Stack

* **Frontend:** React Native
* **Navigation:** React Navigation
* **State Management:** Redux / Context API (based on your setup)
* **API Communication:** Axios / Fetch
* **Styling:** Styled Components or Native StyleSheet

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/trandlane.git
cd trandlane
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Run the app

If you're using Expo:

```bash
npx expo start
```

For CLI projects:

```bash
npx react-native run-android
# or
npx react-native run-ios
```

### 4. Environment Variables (optional)

Create a `.env` file in the root:

```
API_URL=https://yourapi.com
AUTH_SECRET=your_secret_key
```
